Twin Lanterns is an original spot-the-difference game: five hand-drawn scenes (a lantern harbour, a pinewood cabin, a festival market, a coral reef and a hilltop observatory) are each shown as two near-identical pictures side by side, and the player clicks every difference in either picture against the clock, with found markers, a live "how many remain" counter, hints, mistake penalties and rising difficulty across levels.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and click START. Click a difference in either picture; H spends a hint, P pauses, R restarts. To hand the game in the way the grader does, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
